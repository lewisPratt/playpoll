# PlayPoll
#### Under development
## What is it?
PlayPoll is a social gaming app, used to help decide which game a group of friends would like to play.

Start a Poll, select the games to vote on and send the share code to friends. 

Friends retrieve the game options using the share code, cast their vote then sit back and wait for the rest of the group to vote. 
Once done, the results are shown.

Check it out:  [Live Link](https://lewispratt.github.io/playpoll/)
